2026-09-14 feature

Add active-time budgets and deliberate overrides

What — each configured site can use a daily visit budget, daily active-time budget, or permanent block.

Why — repeated checking and focused time need different boundaries, while necessary access should remain possible without becoming effortless.

How — the service worker counts only selected, focused-tab time; exhausted budgets use a visible pause, 5–60 minute stepper, and fresh confirmation code.

2026-08-21 fix

Clarify emergency-override pause and recovery

What — blocked pages and existing-tab overlays show a standalone 15-second countdown and a clear recovery message for a missing confirmation response.

Why — a pause hidden only in a button label and an opaque missing-response error made the override flow hard to recover from.

How — src/shared/messages.ts validates runtime responses; src/ui/blocked.ts and src/content/guard.ts render the countdown.

2026-08-21 feature

Add deliberate friction controls

What — rules can optionally count returns from other tabs, and exhausted budgets offer repeatable emergency overrides.

Why — habits need different counting strictness, while necessary access should remain possible without becoming effortless.

UX — refreshes and navigation within one rule do not count; tab-return counting is opt-in and explained per rule.
