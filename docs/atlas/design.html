Design

Calm, legible friction with one decision per surface.

Principles

2026-09-14
  • Calm over punitive.
  • One decision per surface.
  • Predictable over clever.
  • Trust is visible.

Accent #155de0 Ink #17191f Background #ffffff

Components

2026-09-14
Component Rule
Buttons Accent primary, outlined secondary, visible native disabled state.
Budget type One select offers daily visit budget, daily time budget, or block completely; the matching limit and help text change together.
Override duration stepper Minus and plus controls choose 5–60 minutes in five-minute steps around one plain-language value; arrow keys work on the focused value, and the boundary action is disabled.
Confirmation dialog Separate native dialog, random five-character code, cancellation returns to the duration picker.

Countdown motion conveys no exclusive information. A time budget reports active time remaining, not attention or productivity. Status changes use live regions; all interactions remain keyboard reachable.
