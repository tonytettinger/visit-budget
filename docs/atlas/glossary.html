Glossary

One product term for each durable concept.

Rules and counting

2026-09-13
Rule
A hostname and optional path scope configured as a daily visit budget, daily time budget, or permanent block. Code: src/core/types.ts.
Visit
One counted entry into a visit-limit rule. The first N visits are allowed and entry N + 1 is blocked.
Re-entry
Returning to a rule after viewing a page that does not match that same effective rule.
Tab-return counting
A default-off visit-rule setting that also counts activation of a matching tab after any different tab was active. It never makes refresh, same-rule navigation, or browser-focus return count.
Active time
Time counted only while a rule-matching tab is selected in focused Chrome. It is not an estimate of typing, mouse movement, reading, or attention.
Time budget
A per-rule daily allowance of active time, set instead of a visit budget. Changing between the two takes effect at the next local midnight.
Permanent block
A rule that denies every matching entry and never offers an emergency override.

Deliberate access

2026-09-13
Emergency override
A repeatable high-friction path through an exhausted visit- or time-budget rule. It requires a 15-second pause, a 5–60 minute duration choice in five-minute steps, and exact entry of a random five-character code.
Override duration
The temporary access length chosen for one emergency override. It is not a rule setting or saved preference; it becomes the local expiry of that one override session.
Override challenge
The temporary, fail-closed state containing the pause deadline and expected confirmation code.
Override session
The 5–60 minute access window created by a successful override challenge.
Daily lock
An optional commitment that keeps a rule unchanged until the next local-day reset.
