Product requirements

Visit Budget gives a site one clear daily boundary without pretending to be an unbreakable lock.

Current scope

2026-09-13

People can choose one per-site daily boundary: visits, active time, or a permanent block. Active time counts only while a matching tab is selected in focused Chrome. An exhausted limited site offers a 15-second pause, a 5–60 minute duration choice, and exact entry of a random five-character code.

Everything stays on the device. The extension does not claim to replace self-control: people can still uninstall it or use another browser or profile.

In scope

  • Visit budgets, time budgets, and permanent blocks.
  • Optional visit-only tab-return counting.
  • Repeatable, bounded emergency overrides.
  • Local-only rules, usage, and challenge state.

Out of scope

  • Overrides for permanent blocks.
  • Saved or analysed free-form override reasons.
  • Time reports, attention monitoring, or productivity scoring.
  • Accounts, sync, analytics, advertising, or paid plans.

Key user stories

2026-09-13
Story Observable result
US-1 / US-2 Tab-return counting is opt-in; refreshes, same-rule navigation, and browser focus return do not consume a visit.
US-3 Active time decreases only for a matching selected tab in focused Chrome.
US-4 / US-5 After a 15-second pause, an exhausted visit or time budget can grant only the chosen duration after exact code confirmation.
US-6 No free-form personal text, page content, or browsing data is collected or transmitted.

Edge states and kill criteria

2026-09-13
  • Moving between visit and time budgets takes effect at the next local midnight, so it cannot reset today's allowance.
  • Every override starts a fresh 15-second pause; permanent blocks never offer one.
  • Missing or expired challenge state fails closed.
  • Park time budgets if their focused-tab boundary feels confusing or like surveillance rather than a personal guardrail.
