# Visit Budget visual specification

The production reference is the generated concept image:

`visit-budget-concept.png`

## Design tokens

- Background: true white (`#ffffff`)
- Primary text: near black (`#17191f`)
- Muted text: slate (`#5f6673`)
- Border: cool gray (`#d8dce5`)
- Accent: cobalt (`#155de0`)
- Accent surface: pale blue (`#eaf1ff`)
- Warning: amber (`#9a5a00`)
- Radius: 10px controls and panels, circular site initials
- Typography: system sans-serif with deliberate 12–32px hierarchy
- Motion: 120–180ms functional transitions; disabled with reduced motion

## Component rules

- Open layouts and vertical rule lists; no card grid.
- One-pixel borders and restrained shadows.
- Cobalt is reserved for the primary action, focus, and progress.
- Site identity uses a simple outlined initial, not fetched favicons.
- Controls use native semantic elements with explicit typography.
- Block states are neutral and factual. No shame, gamification, or quotes.
